# avidreader-backend
Backend server for CRUD operations on avidreader webapp.

## Requirements

- Node.js 26.5.0
- npm 11 or newer

With `nvm` installed, select the project runtime with:

```sh
nvm install
nvm use
```

Install dependencies and start the server:

```sh
npm ci
npm start
```

For local development with automatic restarts, run `npm run dev`.
